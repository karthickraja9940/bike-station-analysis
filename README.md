# 🚲 Smart City Bike Sharing Data Analysis | Power BI

## 📌 Project Overview

This project focuses on analyzing smart city bike-sharing data using Microsoft Power BI. The objective is to understand bike station performance, revenue trends, operational efficiency, and city-level performance.

This project demonstrates practical Data Analyst skills, including data cleaning, data transformation, data modeling, DAX calculations, and interactive dashboard development.

## 🎯 Problem Statement

Public bike-sharing systems generate large amounts of data across different cities and stations. Analyzing this data helps identify high-performing cities, revenue patterns, operational inefficiencies, and opportunities for improvement.

The goal is to transform raw bike station data into meaningful business insights and actionable recommendations.

## 🔄 Project Workflow

### 1. Data Import & Exploration
- Import Excel dataset into Power BI.
- Explore dataset structure and columns.
- Understand data types and business information.

### 2. Data Cleaning & Transformation
- Identify and handle missing values.
- Remove duplicate records.
- Correct inconsistent data formats.
- Rename columns and standardize data.
- Transform data using Power Query.

### 3. Data Modeling
- Create a logical data model.
- Identify fact and dimension tables.
- Define relationships between tables.
- Establish appropriate relationship cardinality.

### 4. DAX Calculations
- Create calculated columns where required.
- Develop DAX measures for KPIs.
- Calculate revenue and operational performance metrics.
- Analyze city-level performance.

### 5. Dashboard Development
- Create interactive Power BI dashboards.
- Use appropriate charts and KPI cards.
- Add slicers and filters.
- Visualize city performance and revenue trends.
- Design a clear and user-friendly report.

## 📊 Key Business Questions

- Which cities generate the highest revenue per kilometer?
- Which cities generate the lowest revenue per kilometer?
- How has revenue changed over the years?
- Which cities have low operational cost efficiency?
- Which cities perform better in bike-sharing operations?
- What opportunities exist to improve station performance?
